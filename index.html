Introduction to Cloud Security

Cloud security is the practice of protecting cloud-based data, applications, servers and networks from cyberattacks, unauthorized access and data theft.

Main Goal: Confidentiality, Integrity and Availability.

1. IoT - Internet of Things

IoT refers to physical devices connected to the internet that collect and exchange information.

Examples

  • Smart watches
  • Smart TVs
  • Security cameras
  • Smart home appliances
  • Smart sensors

Security Risks

  • Unauthorized access
  • Weak passwords
  • Device hacking
  • Data theft

2. IAM - Identity and Access Management

IAM manages who can access cloud resources and what actions they are allowed to perform.

Simple Meaning: IAM decides WHO can access WHAT.

  • Authentication - Verifies user identity.
  • Authorization - Decides user permissions.
  • User Management - Manages accounts.
  • Access Control - Controls resource access.

3. MFA - Multi-Factor Authentication

MFA requires two or more different authentication factors before allowing access.

  • Something you know - Password or PIN.
  • Something you have - Mobile phone or security key.
  • Something you are - Fingerprint or face recognition.

Example

  1. Enter your password.
  2. Receive an OTP on your phone.
  3. Enter the OTP.
  4. Access your account.

4. Encryption

Encryption converts readable information (plaintext) into unreadable information (ciphertext) using a key.

Types of Encryption

  • Symmetric Encryption - Uses the same key.
  • Asymmetric Encryption - Uses public and private keys.

Encryption in Cloud

  • Data at Rest - Protects stored data.
  • Data in Transit - Protects moving data.
  • Data in Use - Protects data during processing.

5. Cloud Shared Responsibility Model

This model explains how security responsibilities are divided between the Cloud Service Provider and customer.

Cloud Provider Responsibilities

  • Physical data center security.
  • Hardware and servers.
  • Networking infrastructure.
  • Cloud infrastructure maintenance.

Customer Responsibilities

  • Strong passwords.
  • Enable MFA.
  • Manage IAM permissions.
  • Encrypt sensitive data.
  • Secure applications.

Service Models

Responsibility IaaS PaaS SaaS
Physical Security Provider Provider Provider
Operating System Customer Provider Provider
Applications Customer Customer Provider
Data Customer Customer Customer

6. Quick Revision

  • IoT = Connected Devices
  • IAM = Access Management
  • MFA = Multiple Verification
  • Encryption = Data Protection
  • Shared Responsibility = Provider + Customer

7. Conclusion

Cloud security is essential for protecting digital information and cloud infrastructure. IoT connects devices, IAM controls access, MFA provides extra authentication, encryption protects data and the Shared Responsibility Model divides security duties.
